Politique de confidentialité

Extension QuickCapture · dernière mise à jour : 10 novembre 2026

En bref. Vos captures restent dans votre navigateur. Rien n’est envoyé tant que vous ne créez pas de compte (facultatif) ou ne configurez pas de webhook. Pas de publicité, pas de statistiques d’usage, aucune revente de données. Vous pouvez supprimer votre compte et toutes vos données en ligne en un clic.

Qui est responsable

QuickCapture est développé et publié par quentinvvn, développeur indépendant, responsable du traitement des données décrit ici. Contact : [ADRESSE DE CONTACT].

Sans compte : tout reste sur votre appareil

Les captures (textes, images, liens, screenshots, notes, tags, collections) et vos réglages sont enregistrés dans le stockage local de votre navigateur. Le développeur n’y a pas accès et rien ne quitte votre appareil.

L’extension demande l’accès à tous les sites pour afficher le bouton « Capturer » après une sélection, capturer une image ou une zone de la page, et re-surligner vos textes capturés si vous activez cette option. Le contenu des pages n’est lu qu’au moment d’une capture que vous déclenchez, ou localement pour le surlignage ; il n’est jamais envoyé ailleurs pour ces usages.

Avec un compte (facultatif) : synchronisation et partage

Si vous créez un compte pour retrouver vos captures sur plusieurs appareils, ces données sont transmises :

DonnéesPourquoi
Adresse e-mail et mot de passeCréer le compte et vous connecter. Le mot de passe est stocké sous forme chiffrée (hachée) par le service d’authentification ; il n’est jamais conservé par l’extension.
Vos captures : textes et leur mise en forme, images et screenshots, adresses et titres des pages d’origine, tags, collections, notes, datesLes synchroniser entre vos appareils.

Ces données sont hébergées par Supabase (base de données, authentification et stockage des images), qui agit comme sous-traitant, dans la région [RÉGION SUPABASE]. Chaque compte n’a accès qu’à ses propres données. Les échanges sont chiffrés (HTTPS).

Partage de collection. Si vous créez un lien de partage, toute personne disposant du lien peut consulter la collection (titres, contenus, images, tags et adresses d’origine, mais pas vos notes). Vous pouvez arrêter le partage à tout moment ; le lien cesse alors de fonctionner. La page de partage est hébergée par GitHub Pages, qui peut enregistrer l’adresse IP des visiteurs dans ses journaux techniques.

Webhook (facultatif)

Si vous l’activez, chaque nouvelle capture est envoyée à l’adresse que vous avez choisie (Zapier, Make, votre serveur…). Ces données vont directement de votre navigateur à ce service ; le développeur de QuickCapture ne les reçoit pas. Le traitement relève alors du service que vous avez choisi.

Ce que QuickCapture ne fait pas

  • aucune publicité, aucun outil de statistiques ou de suivi ;
  • aucune vente, location ou cession de données ;
  • aucune utilisation de vos données pour autre chose que les fonctions décrites ici ;
  • aucun code chargé depuis Internet : tout le code de l’extension est inclus dans le paquet publié.

Le lien « Soutenir le projet » ouvre une page Buy Me a Coffee dans un nouvel onglet ; aucune donnée ne lui est transmise par l’extension.

Durée de conservation

Les données en ligne sont conservées tant que votre compte existe. Une capture supprimée est effacée de votre compte à la synchronisation suivante (seul un identifiant technique, sans contenu, est gardé pour propager la suppression à vos autres appareils). La suppression du compte efface immédiatement le compte, les captures, les images et les liens de partage.

Vos droits

Conformément au RGPD, vous pouvez à tout moment :

  • accéder à vos données et les récupérer : dashboard → Exporter → JSON (sauvegarde complète) ;
  • les rectifier : modifiez une capture depuis le dashboard ;
  • les effacer : options de l’extension → « Supprimer mon compte et mes données en ligne » ;
  • vous opposer au traitement : déconnectez-vous ; plus rien n’est envoyé.

Pour toute question ou demande : [ADRESSE DE CONTACT]. Vous pouvez aussi adresser une réclamation à la CNIL (cnil.fr).

Modifications

En cas de changement de cette politique, la date ci-dessus est mise à jour. Un changement important (nouvelle donnée transmise, nouveau prestataire) sera signalé dans les notes de version de l’extension.
